Data Visualization Dashboard
Project Description

This project is a data visualization desktop application developed for the Sales Department of a data analysis company. The goal is to empower managers and analysts to visually explore and present data in a clear, intuitive, and interactive manner, even to non-technical stakeholders.

The application supports dynamic data exploration, allowing users to add, remove, move, and customize charts based on their analysis needs. It is built using modern C# technologies and follows best practices such as the MVVM architecture and SOLID principles for clean, modular, and maintainable code.
🛠 Technologies Used

    C#

    Avalonia UI - for cross-platform desktop UI

    CommunityToolkit.Mvvm - to support MVVM structure

    LiveCharts2 - for rendering modern and interactive charts

    CsvHelper - for reading and parsing CSV files

    LINQ - for efficient data filtering, grouping, and sorting

 Key Features
 Basic Features

    MVVM Architecture: Clean separation of concerns using Model, View, and ViewModel.

    Load CSV Data: Read and parse dataset from CSV files.

    Preset Queries (5-10): Choose from predefined data queries for instant visualization.

    Interactive Charts: Display multiple chart types, including:

        Pie Charts

        Bar Charts

        Line Charts

    Control Panel: Lists all available queries for users to select.

    Dashboard Display: Selected charts appear dynamically on the dashboard.

    Remove Chart Button: Easily remove any displayed chart.

✨ Advanced Features

    Drag-and-Drop Charts: Users can rearrange charts freely on the dashboard.
    Dynamic Query Builder: Customize queries on-the-fly by setting filters, sorting, and grouping options.
